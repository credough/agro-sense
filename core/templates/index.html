System Capabilities

Built for the Filipino farmers

Every feature in AgroSense traces back to a real field constraint — not a technical preference.

Real-Time Weather Integration
Pulls 3–5 day forecasts from Open-Meteo. Confidence level computed from forecast variance — not AI-generated.
IRRI AWD Decision Engine
Deterministic, rule-based engine grounded in IRRI's Alternate Wetting and Drying framework. Outputs are fully explainable and auditable — no black box.
Plain Filipino Recommendations
RAG-powered LLM generates guidance in plain Tagalog at a Grade 6 literacy level. Constrained to IRRI and PhilRice data — no hallucinations, no generic advice.
AI-Assisted Photo Analysis
Upload a field photo and AgroSense infers water status using the Claude API — no technical terminology needed. The photo replaces complex soil sensor inputs.
